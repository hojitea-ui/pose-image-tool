# 원하는 포즈로 이미지 만드는 도구 (ControlNet OpenPose)

## 도구 설명
ControlNet과 OpenPose를 활용하여 참조 인물 사진에서 관절 포즈(Skeleton)를 추출하고, 설정한 프롬프트를 통해 지정한 포즈를 따라 하는 새로운 이미지를 생성하는 튜토리얼 도구입니다.

## 사용법
1. **Colab 실행 환경 설정**
   - Google Colab에서 `pose_tool.ipynb` 노트를 엽니다.
   - 상단 메뉴 [런타임] - [런타임 유형 변경]에서 `T4 GPU`를 선택합니다.

2. **셀 순서대로 실행**
   - **[셀 1]**: 필수 라이브러리를 설치하고 ControlNet 및 OpenPose 관련 모델을 로드합니다.
   - **[셀 2]**: 참조 이미지(`samples/pose_01.png` 또는 `samples/pose_02.png`)를 입력하고 OpenPose를 통해 관절 포즈를 추출합니다.
   - **[셀 3]**: 프롬프트를 입력하고 ControlNet을 이용해 새로운 이미지를 생성합니다.
   - **[셀 4]**: 생성된 결과를 확인하고 저장합니다.

3. **결과 확인**
   - 생성된 이미지는 `/content/samples/` 디렉토리에서 확인할 수 있습니다.

## 한계 및 관찰 소감

- **장점:** 참조 사진의 의상이나 배경과 관계없이 인물의 관절 포즈를 조건으로 활용할 수 있으며, 서로 다른 콘셉트의 프롬프트에도 참조 포즈를 적용할 수 있음.
- **한계:** 참조 이미지의 자세가 복잡하거나 손과 발이 작게 표현된 경우 OpenPose가 일부 관절을 정확하게 검출하지 못할 수 있으며, 이로 인해 생성 이미지의 포즈에도 차이가 발생할 수 있음.
- **생성 품질:** SD v1.5 기반 파이프라인 특성상 손가락, 얼굴, 의상 등의 세부 표현이 일부 뭉개지거나 왜곡될 수 있음.
